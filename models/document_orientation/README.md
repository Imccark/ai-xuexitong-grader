# Document orientation model

This directory contains the official PaddleOCR `PP-LCNet_x1_0_doc_ori`
four-way document orientation classifier exported to ONNX.

- Source: <https://www.paddleocr.ai/main/version3.x/module_usage/doc_img_orientation_classification.html>
- Runtime labels: current page orientation `0`, `90`, `180`, `270`; the
  correction applied by this project is the inverse clockwise rotation
- ONNX SHA-256: `af9a0a4f317ff0709ce752067807f819cb15d883f8ecad89f28df1c6ee2d9c92`
- Upstream project license: Apache-2.0

The model runs locally. No homework image is uploaded for orientation
classification.
